# P145 高级设置 · 发版流程

> 两个仓库（Gitee + GitHub）之间**没有自动同步**，每次都要推两遍。
> 下面这些 alias 已经配在本地 `.git/config` 里。

## 一、日常提交（只改代码）

```bash
git add -A
git commit -m "feat: xxx"
git pushall          # = 推 main 到 github + gitee
```

## 二、发版（改版本号 → 构建 → 发 Release）

```bash
# 1. 改版本号（三处）
#    AndroidManifest.xml          versionCode / versionName
#    MainActivity.java            v2.x 文案 + aboutText 的版本行
#    res/layout/activity_main.xml 关于页的 "高级设置 v2.x"

# 2. 构建
powershell -File build.ps1
cp build/advanced-settings.apk dist/advanced-settings.apk

# 3. 更新 version.json
#    versionCode / versionName / url / mirror / notes

# 4. 提交并双推
git add -A
git commit -m "release: vX.Y"
git pushboth          # main + tags 一起推

# 5. 打 tag 并双推
git tag vX.Y
git pushboth

# 6. GitHub Release（gh 自动带附件）
$env:GH_TOKEN = "ghp_xxx"
gh release create vX.Y dist/advanced-settings.apk --title "vX.Y · 标题" --notes "..."

# 7. Gitee Release（API + curl 上传附件）
curl -X POST "https://gitee.com/api/v5/repos/magiskalive/P145-AdvancedSettings/releases" \
  -H "Content-Type: application/json" \
  -d '{"tag_name":"vX.Y","name":"vX.Y · 标题","body":"...","target_commitish":"main"}'
# 拿到返回的 id，然后：
curl -X POST "https://gitee.com/api/v5/repos/magiskalive/P145-AdvancedSettings/releases/<id>/attach_files" \
  -F "access_token=<GITEE_TOKEN>" -F "file=@dist/advanced-settings.apk"
```

## 三、版本号规范

采用 **SemVer 三段式**：`MAJOR.MINOR.PATCH`（如 `2.4.0`）。三处必须同步：

| 位置 | 字段 | 示例 |
|---|---|---|
| `AndroidManifest.xml` | `versionCode` / `versionName` | `16` / `2.4.1` |
| `version.json` | `versionCode` / `versionName` | `16` / `2.4.1` |
| git tag | 标签名 | `v2.4.1` |

**Release 标题只用纯版本号**（`v2.4.1`），说明写在正文里 —— 避免把中文当成版本号。

**检测更新的真实依据是 `versionCode`（整数）**，不是 versionName 字符串：

```java
if (info.versionCode > localVersionCode) { 提示更新 }
```

所以 versionName 写成 `2.4`、`2.4.0` 还是 `v2.4.0` 都不影响检测，但为了可读性和规范，统一三段式。

## 四、为什么不能只推 GitHub

| 方式 | 是否可行 | 说明 |
|---|---|---|
| **手动双推**（推荐） | ✅ | 实时、可靠，一条 `git pushall` 搞定 |
| Gitee 仓库镜像 | ⚠️ | 需在 Gitee 网页手动绑定，**定时同步**（有延迟），且 **Release 附件不同步** |
| GitHub Actions 同步 Gitee | ⚠️ | 要配 secret + workflow，维护成本高 |
| 只推 GitHub 等 Gitee 自动拉 | ❌ | **Gitee 不会主动拉取**，没有这功能 |

**结论**：代码用 `git pushall` 双推；Release 附件必须两个平台各传一次。

## 五、已配置的 alias

```bash
git pushall    # 推 main 到 github + gitee
git pushtags   # 推所有 tag 到 github + gitee
git pushboth   # main + tags 一起推（发版用这个）
```

查看：`git config --local --get-regexp alias`
